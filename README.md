# Hi, I'm Miguel Payá Vañó 👋🏻

**Full-Stack Developer — Alcoy, Spain.** I build for the web with a bias most portfolios don't: **handcrafted, dependency-free, and fast by construction.** My shipped sites run on plain HTML, vanilla CSS and vanilla JavaScript — no framework, no bundler, no runtime dependencies, no trackers — and still score **100/100 PageSpeed Insights across Performance, Accessibility, Best Practices and SEO**, with **A+ security headers** and **zero third-party network requests**.

I treat **performance, accessibility, security and privacy as acceptance criteria, not afterthoughts.** Perfect Core Web Vitals, WCAG 2.1 AA, a strict Content-Security-Policy with no `unsafe-inline`, HSTS preload, and no cookies or analytics — because a page shouldn't need to watch you to work.

That's my personal work. Professionally I also ship **full-stack apps with frameworks** — Vue 3 and React on the front, Node/Express + MongoDB on the back — so I choose the tool to fit the job rather than the other way around.
